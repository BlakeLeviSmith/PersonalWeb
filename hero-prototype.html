01 · Source
Pull Charlotte road data from OpenStreetMap via the Overpass API, filtered to motorway, trunk, and primary highway tags. One-time download, no live API in production.
02 · Render
Run a Python script using osmnx and shapely to convert the OSM data to clean SVG paths. Output is a single SVG with one path per road class.
03 · Style
Clean the SVG by hand in Figma, set stroke weights by road class, crop to frame, add the markers layer. Final asset is one static SVG, roughly 30 to 50KB.
